Add a nice credit to Starlight or Astro at the bottom of Table of Contents.

## Prerequisites

You will need to have a Starlight website set up.
If you don't have one yet, you can follow the ["Getting Started"](https://starlight.astro.build/getting-started) guide in the Starlight docs to create one.

## Installation

import { Steps, Tabs, TabItem } from "@astrojs/starlight/components";

<Steps>

1. `starlight-cooler-credit` is a Starlight [plugin](https://starlight.astro.build/reference/plugins/). Install it by running the following command in your terminal:

   <Tabs syncKey="pkg">

   <TabItem label="npm">

   ```sh
   npm install starlight-cooler-credit
   ```

   </TabItem>

   <TabItem label="pnpm">

   ```sh
   pnpm add starlight-cooler-credit
   ```

   </TabItem>

   <TabItem label="Yarn">

   ```sh
   yarn add starlight-cooler-credit
   ```

   </TabItem>

   </Tabs>

2. Configure the plugin in your Starlight [configuration](https://starlight.astro.build/reference/configuration/#plugins) in the `astro.config.mjs` file.

   ```diff lang="js"
   // astro.config.mjs
   import starlight from '@astrojs/starlight'
   import { defineConfig } from 'astro/config'
   +import starlightCoolerCredit from 'starlight-cooler-credit'

   export default defineConfig({
     integrations: [
       starlight({
   +      plugins: [starlightCoolerCredit()],
         title: 'My Docs',
       }),
     ],
   })
   ```

3. [Start the development server](https://starlight.astro.build/getting-started/#start-the-development-server) to preview the plugin in action.

</Steps>

The Starlight Cooler Credit plugin behavior can be tweaked using various [configuration options](/configuration/).

## Component overrides

The Starlight Cooler Credit plugin uses Starlight [component overrides](https://starlight.astro.build/guides/overriding-components/) for the following components:

- [`TableOfContents`](https://starlight.astro.build/reference/overrides/#tableofcontents) to add the [`CreditReferenceCard`](/credit-reference-card/) component at the bottom of the table of contents on large viewports.
- [`Pagination`](https://starlight.astro.build/reference/overrides/#pagination) to add the [`CreditReferenceCard`](/credit-reference-card/) component below the pagination links on smaller viewports where the table of contents sidebar is not visible.

If you have a custom override for one of these components in your Starlight project, you will need to manually render the matching component from the Starlight Cooler Credit plugin in your custom component.

For example, for a custom `TableOfContents` override, render the plugin component _after_ the default Starlight component:

```diff lang="astro"
---
// src/components/overrides/TableOfContents.astro
import Default from '@astrojs/starlight/components/TableOfContents.astro'
+import StarlightCoolerCreditTableOfContents from 'starlight-cooler-credit/components/TableOfContents.astro'
---

<Default><slot /></Default>
<p>Custom content in the TableOfContents override</p>
+<StarlightCoolerCreditTableOfContents />
```
