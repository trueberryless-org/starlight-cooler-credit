# `starlight-cooler-credit-docs`

Documentation for the `starlight-cooler-credit` Starlight plugin, deployed at [starlight-cooler-credit.netlify.app](https://starlight-cooler-credit.netlify.app).

## Documentation

Run the documentation locally by running the following command in your terminal:

```shell
pnpm run dev
```

Content can be found in the [`src/content/docs/`](https://github.com/trueberryless-org/starlight-cooler-credit/tree/main/docs/src/content/docs) directory.
